## ✨ Возможности и функционал

- 🗡️ **Auto Swing / Train Power**: Быстрая прокачка силы меча с настраиваемой задержкой.
- 🎯 **Auto Mobs & Bosses**: Безопасный фарм сверху (`Safe Elevation`), мобы не могут нанести урон.
- 🔄 **Auto Rebirth**: Автоматическое перерождение без задержек.
- 🛡️ **Auto Equip Best**: Автоматический выбор и экипировка сильнейшего оружия в инвентаре.
- 🗺️ **Auto Buy Zones**: Разблокировка новых миров и локаций при накоплении монет.
- 🔁 **Failsafe System**: Мгновенный возврат на сохранённую точку при респавне, смерти или падении в бездну.
- 🛡️ **Built-in Anti-AFK**: Защита от кика за неактивность (20 минут).
- 📉 **FPS Boost**: Отключение 3D-рендеринга для фарма 24/7 с минимальной нагрузкой на GPU/CPU.
- 📡 **Discord Webhook**: Автоматические отчёты о балансе, силе, победах и аптайме.
- 🗑️ **Clean Unload**: Полная выгрузка из памяти в один клик.
