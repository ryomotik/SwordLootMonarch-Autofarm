## 🚀 Быстрый запуск (Loadstring)

Скопируйте и вставьте строку в любой современный Luau-экзекутор (Wave, Synapse, Solara, Arceus, Delta, Fluxus и др.):

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/ryomotik/SwordLootMonarch-Autofarm/main/main.lua?v=" .. tostring(os.time()), true))()
```

## ✨ Основной функционал (Fluent Amethyst Edition)

- 🟣 **Fluent UI (Amethyst Purple)**: 
  - Дефолтные ультра-плавные анимации (`TweenService Quart` / Spring physics).
  - Гладкие скруглённые края на всех окнах, карточках и кнопках (`UICorner`).
  - Классический левый сайдбар с иконками и скользящим вертикальным индикатором активной вкладки (`Selector Pill`).
  - Плавный переход вкладок с выезжанием и плавным растворением (`Fade & Slide`).
  - Плашка профиля разработчика **👑 Ryomotik** внизу сайдбара.

- ⚡ **Непрерывный авто-кликер силы**:
  - Фарм силы через прямой сетевой протокол `TrainManualClick = 220` на софт-капе ~20 кликов/сек.
  - Сила копится непрерывно даже во время бега, переходов и босс-файтов.
  - Настраиваемый слайдер частоты кликов (5..25 /сек).

- 🔄 **Авто-перерождение (Auto Rebirth)**:
  - Автоматический вызов `Net.InvokeServer(Msg.PlayerRebirth)` сразу же по достижении необходимого уровня для следующего перерождения.
  - Живое отслеживание текущего тира перерождения и точного процента прогресса.

- 🏰 **Умный фарм этапов (Stages 1..38)**:
  - Автоматическое отключение коллизий на всех 187 барьерах и воротах (`No-Clip`), исключающее застревания и отбрасывания.
  - Чёткая пошаговая цепочка прохождения: активация зоны этапа ➔ запрос спавна врагов ➔ авто-каст навыков ➔ фиксация победы в WinArea.
  - Кнопки быстрого ручного контроля: `Следующий этап ▶` и `В лобби 🏠`.
  - Слайдер задержки зачистки этапа.

- 💎 **Авто-атака и авто-каст способностей**:
  - Автоматическое использование навыков меча и ударов по кулдауну через `SetAutoCast`.

- 🧲 **Мгновенный сбор лута (DropPickup)**:
  - Перехват серверного события появления наград `DropSpawn` и моментальный сбор предметов через `DropPickup = 151`.

- 📈 **Телеметрия охотника**:
  - Отображение текущей мощности (K/M/B/T), уровня, номера этапа и прогресс-бара до следующего Rebirth.
