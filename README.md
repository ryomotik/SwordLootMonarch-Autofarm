## 🚀 Быстрый запуск (Loadstring)

Скопируйте и вставьте строку в любой современный Luau-экзекутор (Wave, Synapse, Solara, Arceus, Delta, Fluxus и др.):

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/ryomotik/SwordLootMonarch-Autofarm/main/main.lua?v=" .. tostring(os.time()), true))()
```

## ✨ Основной функционал v3.2 (Clean Farm Edition)

- 🎯 **Единая чистая вкладка «Фарм»**: Весь лишний мусор и разрозненные категории убраны. Все ключевые функции собраны в одном компактном и удобном меню!
- 🚶 **Проход по локациям (Ground Walker)**: Персонаж идёт ногами по земле с расчётом высоты рельефа, зачищает мобов в коридоре и переходит на следующие зоны.
- ⚰️ **Авто-возврат после смерти**: При гибели персонажа скрипт мгновенно нажимает серую кнопку «Вернуться в город» на экране `DeathGui` и автоматически перезапускает прохождение этапа.
- 👣 **Умный подход к ценному дропу**: Персонаж лично подходит к выпавшему луту (Мифики+ и сундуки), делает человеческую секундную паузу для гарантированного подбора и спокойно идёт дальше.
- ⚔️ **Авто-клик / Тренировка силы**: Нативный кликер тренировки силы с настраиваемой задержкой удара.
- 👑 **Авто-экипировка лучшего меча**: Автоматически выбирает и экипирует сильнейший меч (`InvEquipBest`).
- 🔄 **Авто-перерождение**: Мгновенный Rebirth при накоплении нужного количества силы/монет.
- 🛡️ **Anti-Kick & Capability Protection**: Полный обход ошибок безопасности Luau (`Plugin capability`), встроенный Anti-AFK и защита от лимитов пакетов.
- 🟣 **Amethyst Purple Fluent UI**: Стильный фиолетовый неоновый интерфейс с плавным перетаскиванием окна за шапку без блокировки кнопок.
- 🗑️ **Clean Unload**: Полная и бесследная выгрузка скрипта и интерфейса в один клик.
